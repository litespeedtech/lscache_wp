# Security Policy

## Reporting Security Bugs

Please report potential LiteSpeed Cache vulnerabilities through the [Patchstack Vulnerability Disclosure Program](https://patchstack.com/database/vdp/litespeed-cache) or by email to `support@litespeedtech.com`. You may also open a private ticket from the [LiteSpeed Client Area](https://www.litespeedtech.com/support).

Do not publish suspected vulnerabilities in a GitHub issue or support forum before they are resolved.

Include the affected plugin, WordPress, and PHP versions; relevant settings; reproduction steps or a proof of concept; and the expected impact.

See [Reporting Vulnerabilities](https://www.litespeedtech.com/report-security-bugs) for LiteSpeed's current reporting policy.
